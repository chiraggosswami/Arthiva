---
name: Margin Pilot feature extensions
description: Project-specific scope for adding new Margin Pilot capabilities.
---

For feature additions to Margin Pilot, reuse the existing engine and saved order data, add screens alongside existing pages, and keep established pages intact except for small integrations needed to share configuration.

**Why:** the user explicitly requested this when extending the app with delivery rescue, RTO recovery, and journey rules.

**How to apply:** Build future modules as additive routes and components connected to the current state and engine instead of replacing existing screens.
